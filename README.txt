# موقع علاء الدين

موقع ثابت (HTML/CSS/JS) جاهز لعرض تطبيق علاء الدين وتحميله مباشرة على Android.

## وضع ملف التطبيق

ضع ملف APK النهائي داخل:

downloads/AlaaAldin.apk

إذا كان اسم ملف APK مختلفاً، عدّل رابط التحميل في `index.html`.

## تغيير الإصدار

في `index.html` ابحث عن:

<span id="version">1.0.0</span>

واستبدل 1.0.0 برقم الإصدار الحالي.

## الرفع على الاستضافة

ارفع كامل محتويات المجلد إلى الاستضافة بحيث يكون `index.html` في المجلد الرئيسي.

الموقع لا يحتاج إلى PHP أو قاعدة بيانات.
